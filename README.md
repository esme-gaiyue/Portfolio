# Gaiyue Li — Personal Portfolio / 个人求职网站

A static bilingual website ready for GitHub Pages. No build tools or server needed.

## Deploy / 部署
1. Create a public GitHub repository named `gaiyue-portfolio` (or any name).
2. Upload **all files and folders** in this ZIP, keeping `index.html` at the repository root.
3. Open **Settings → Pages → Build and deployment**.
4. Choose **Deploy from a branch**, branch **main**, folder **/(root)**, then Save.
5. Your website will appear at `https://YOUR-USERNAME.github.io/gaiyue-portfolio/` after GitHub finishes publishing.

## Files / 文件
- `index.html`, `style.css`, `script.js`: website source
- `assets/cv/*.pdf`: downloadable PDFs converted from the 5 supplied Word documents

## Privacy / 隐私
The webpage does not display phone numbers, but **the PDFs retain the phone numbers and other personal information from the original documents**. The original Chinese CV may contain a portrait photo. GitHub Pages on a public repository makes these PDFs publicly accessible. Review and redact the PDFs before publishing if you do not want this information public.
